# SrIruma Homebrew Tap

A Homebrew tap for tools published by [SrIruma](https://github.com/SrIruma).

## Usage

```sh
brew tap SrIruma/tap
brew install <formula>
```

## Available formulae

| Formula | Description |
|---|---|
| `repoctx` | Keep AI coding-agent context files (AGENTS.md, CLAUDE.md) truthful. |

More formulae may be added over time.
